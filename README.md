# Shadow Studio prototype

Clickable prototype of the Aalpha client delivery console ("Studio") for Shadow / Headroom.
Sample clients and numbers only. State lives in the browser (localStorage); "Reset demo" restores the seed.

- Design: `Aalpha/Strategy/Shadow-Studio-Admin-Design-2026-10-26.md` in the Knowledgebase.
- Rules (stage, risk, guarantees, Requirements for Success, alerts, next actions): `src/lib/engine.ts`.
- Sample clients: `src/lib/seed.ts`.

Run: `npm run dev` (use the Apple Silicon node in /opt/homebrew/bin).
